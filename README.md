# Buku Utang WiFi — Mikasa Field Ledger
1. Ekstrak ZIP ini.
2. Upload semua file ke root repository GitHub.
3. Hubungkan repository dengan Netlify. Build command kosong, publish directory `.`.
4. Setelah terbit via HTTPS, buka di Chrome Android lalu pilih Install app atau Tambahkan ke layar utama.

Fitur: daftar pelanggan, cari, tambah/edit, pencatatan pembayaran, arsip/pulihkan, hapus dengan pengamanan, audit, ekspor backup.

**Penting:** data disimpan lokal pada browser (localStorage), bukan database cloud. Tidak otomatis tersinkron antarperangkat. Ekspor backup rutin. Untuk pencatatan operasional, pertimbangkan backend autentikasi dan backup server.
